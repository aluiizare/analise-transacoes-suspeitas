# Análise de Transações Suspeitas

## Sobre o projeto 

Este projeto tem como objetivo analisar transações financeiras e identificar possíveis operações suspeitas a partir de diferentes critérios e padrões. 

O projeto foi desenvolvido como parte do meu portifólio profissional, com foco em análise de dados e prevenção a fraudes financeiras. 

## Objetivos 

- Analisar dados de transações financeiras;
- Identificar padrões que possam indicar operações suspeitas;
- Aplicar critérios de análise para classificação das transações;
- Desenvolver conhecimentos em análise de dados, SQL e Python;
- Apresentar os resultados de forma clara e organizada.

  ## Tecnologias

- Python
- SQL
- GitHub
- Análise de dados
