# Regras de Análise

## Objetivo

Identificar transações que apresentam características que podem justificar uma análise mais detalhada.

## Critérios utilizados

### 1. Valor elevado
Transações com valores significativamente maiores que o padrão observado na base podem ser encaminhadas para análise.

### 2. Horário incomum
Transações realizadas durante a madrugada podem receber atenção adicional, especialmente quando combinadas com outros indicadores.

### 3. Localização
A localização da transação pode ser utilizada como um dos elementos da análise, principalmente quando houver mudanças ou padrões incomuns.

### 4. Combinação de indicadores
Um único indicador não determina que uma transação seja uma fraude. A análise deve considerar a combinação de diferentes características.

## Observação

Os dados utilizados neste projeto são fictícios e foram criados exclusivamente para fins de estudo e desenvolvimento do portfólio.
